🧠 Simple Quiz App
This is a basic JavaScript quiz application where users can test their knowledge by answering multiple-choice questions. The app checks your answers, updates the score, and allows you to reset the quiz at any time.
[This project I created just to consolidate my learning of JS]

🚀 Features
3 multiple-choice questions

Real-time answer validation

Score tracking

Reset button to try again

Clean and interactive UI

🛠️ Built With
HTML

CSS

JavaScript (Vanilla)

📦 How to Run
Clone the repository or download the files.

Open the index.html file in your browser.

Click Start, answer the questions, then click Submit to see your score.

Use the Reset button to try again!

💡 Notes
The correct answers are hardcoded.

You can submit each answer only once per session.

Simple structure, easy to expand with more questions or features.
